रामायण हाडु

जगन्नाथ दासरु

आरभि
None
असुर बाधिसुतिरलु ऋषिगळु स्तुतिमाडे
दशरथन गर्भदलि जनिसि बन्दे |
शिशुवागि कौसलेगे बाललीलेय तोर्दु
कुशलदिं नाल्वर कूडे बेळेदे ||॥1॥
None
असुररने बडिदट्टि ऋषिय यागव काय्दु
वसुधेयोळु शिलेयन्नु सतिय माडि |
मिथिलपट्टणकैदि मृडन धनुवने मुरिदु
शशिमुखि जानकिय करव पिडिदु ||॥2॥
None
पथदोळगे बरुत भार्गवरोडने होराडि
दशरथगे एकीभाववने तोरि |
परमहरुषदलि साकेतनगरिगे बन्दु
किरियमातेय कठिणनुडि केळि ||॥3॥
None
चित्रकूटके बन्दु कृत्यवेल्लव नडेसि
भ्रातृ भरतनिगे पादुकेयसित्तु |
वनदोळगे सञ्चरिसि घनकार्यगळ माडि
हनुमन कळुहि मुद्रिकेय कोडलु ||॥4॥
None
मित्रे जानकिगरुहि रत्नकोण्डु बरलु
अत्यन्त हरुषदलि शरधिकट्टि |
दुष्ट राक्षसकुलव कुट्टि बेरने सवरि
सृष्टिसुते जानकिय अग्नि होगिसि ||॥5॥
None
पट्टणके बन्दु भरतनिगे पेळे
अष्टगङ्गे उदकवने तन्दु |
अष्टे ऋषिगळु एल्ल कूडिकोण्डु
पट्टाभिषेकवनु माडुतिरलन्दु ||॥6॥
None
सृष्टियोळु जगन्नाथविठलनिगे
पुष्प वृष्टिगळन्नु करेदराग ||॥7॥

ರಾಮಾಯಣ ಹಾಡು

ಜಗನ್ನಾಥ ದಾಸರು

ಆರಭಿ
None
ಅಸುರ ಬಾಧಿಸುತಿರಲು ಋಷಿಗಳು ಸ್ತುತಿಮಾಡೆ
ದಶರಥನ ಗರ್ಭದಲಿ ಜನಿಸಿ ಬಂದೆ |
ಶಿಶುವಾಗಿ ಕೌಸಲೆಗೆ ಬಾಲಲೀಲೆಯ ತೋರ್ದು
ಕುಶಲದಿಂ ನಾಲ್ವರ ಕೂಡೆ ಬೆಳೆದೆ ||॥1॥
None
ಅಸುರರನೆ ಬಡಿದಟ್ಟಿ ಋಷಿಯ ಯಾಗವ ಕಾಯ್ದು
ವಸುಧೆಯೊಳು ಶಿಲೆಯನ್ನು ಸತಿಯ ಮಾಡಿ |
ಮಿಥಿಲಪಟ್ಟಣಕೈದಿ ಮೃಡನ ಧನುವನೆ ಮುರಿದು
ಶಶಿಮುಖಿ ಜಾನಕಿಯ ಕರವ ಪಿಡಿದು ||॥2॥
None
ಪಥದೊಳಗೆ ಬರುತ ಭಾರ್ಗವರೊಡನೆ ಹೋರಾಡಿ
ದಶರಥಗೆ ಏಕೀಭಾವವನೆ ತೋರಿ |
ಪರಮಹರುಷದಲಿ ಸಾಕೇತನಗರಿಗೆ ಬಂದು
ಕಿರಿಯಮಾತೆಯ ಕಠಿಣನುಡಿ ಕೇಳಿ ||॥3॥
None
ಚಿತ್ರಕೂಟಕೆ ಬಂದು ಕೃತ್ಯವೆಲ್ಲವ ನಡೆಸಿ
ಭ್ರಾತೃ ಭರತನಿಗೆ ಪಾದುಕೆಯಸಿತ್ತು |
ವನದೊಳಗೆ ಸಂಚರಿಸಿ ಘನಕಾರ್ಯಗಳ ಮಾಡಿ
ಹನುಮನ ಕಳುಹಿ ಮುದ್ರಿಕೆಯ ಕೊಡಲು ||॥4॥
None
ಮಿತ್ರೆ ಜಾನಕಿಗರುಹಿ ರತ್ನಕೊಂಡು ಬರಲು
ಅತ್ಯಂತ ಹರುಷದಲಿ ಶರಧಿಕಟ್ಟಿ |
ದುಷ್ಟ ರಾಕ್ಷಸಕುಲವ ಕುಟ್ಟಿ ಬೇರನೆ ಸವರಿ
ಸೃಷ್ಟಿಸುತೆ ಜಾನಕಿಯ ಅಗ್ನಿ ಹೊಗಿಸಿ ||॥5॥
None
ಪಟ್ಟಣಕೆ ಬಂದು ಭರತನಿಗೆ ಪೇಳೆ
ಅಷ್ಟಗಂಗೆ ಉದಕವನೆ ತಂದು |
ಅಷ್ಟೆ ಋಷಿಗಳು ಎಲ್ಲ ಕೂಡಿಕೊಂಡು
ಪಟ್ಟಾಭಿಷೇಕವನು ಮಾಡುತಿರಲಂದು ||॥6॥
None
ಸೃಷ್ಟಿಯೊಳು ಜಗನ್ನಾಥವಿಠಲನಿಗೆ
ಪುಷ್ಪ ವೃಷ್ಟಿಗಳನ್ನು ಕರೆದರಾಗ ||॥7॥
